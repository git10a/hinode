# スケジュールのイベントカード

`/schedule` は Luma の公開 iCal フィードをサーバーで取得し、HINODE のカードとして表示する。

- 公開カレンダー: https://luma.com/hinode
- 公開フィード: https://api.luma.com/ics/get?entity=calendar&id=cal-JWxU0jyUqr7q0ZS
- ページとフィードは5分ごとに再検証する。APIキーやLuma Plusは不要。
- 開催名・日時・場所・詳細リンクはフィードに従う。終了済み・中止の予定は表示しない。
- フィードには写真がないため、定例ランは承認済みの場所別写真を使用する。その他のイベントは既存のHINODE画像を使用する。写真の対応は `lib/luma.js` で管理する。
- フィード取得失敗と開催予定なしを区別し、どちらもLuma・Stravaへのリンクを表示する。
- 参加予定の登録は任意。Strava・Lumaのどちらでもよく、未登録でも参加できる。登録すると雨天中止などのお知らせを受け取りやすくなると案内する。

データ読み込みの確認:

```sh
node --test tests/luma.test.mjs
```

テストのフィードは公開カレンダーの2026-10-29取得分。長い行の折り返し、日本時間の日付、終了・中止、取得失敗を検証する。
